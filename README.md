# FreshMart Supermarkets – Business Analysis Case Study

## Project Overview
This case study investigates declining customer basket value at FreshMart Supermarkets despite an increase in customer footfall. The project focuses on understanding customer purchasing behaviour, identifying possible causes of declining transaction value and providing data-driven recommendations to improve business performance.

## Objectives
- Investigate changes in average basket value.
- Analyse the number of items purchased per transaction.
- Identify trends across stores, provinces and store formats.
- Investigate possible factors affecting customer spending.
- Provide data-driven recommendations.
